# 三、硬件系统

## 3.1 双电机系统

| 功能 | 电机类型 | 驱动方式 | 作用 |
|------|---------|---------|------|
| 收线盘旋转 | 直流电机 | MOS 管 PWM 驱动（单向） | 带动料盘旋转收卷耗材，支持无级调速、启停 |
| 排线移动 | 360 连续旋转舵机 | 舵机信号线直驱（PWM） | 连接丝杆，舵机旋转带动丝杆转动，驱动耗材沿盘宽左右往复移动 |

**运动学关系**：

- 收线盘旋转 = 主运动，决定绕线速度
- 排线移动 = 从运动，跟随收线盘旋转同步移动
- 理想关系：料盘每转一圈，排线移动「单圈绕线移动距离」（默认 = 线径）
- 排线移动速度通过舵机 PWM 控制，实际移动速度需标定后写入配置文件

## 3.2 传感器系统

| 传感器 | 数量 | 安装位置 | 作用 |
--------|------|---------|------|
| 霍尔 A3144 (KY-003) A | 1 套 | 从动轮 | 计量耗材实际出线长度 |
| 霍尔 A3144 (KY-003) B | 1 套 | 料盘 | 计量料盘旋转脉冲/圈数 |
| Endstop 限位（滚轮摆杆式） | 1 个 | 排线机构最左端 | 最左物理限位标记 + 周期性原点校准 |
| 磁铁 N35 直径6x2mm | 若干 | 从动轮 + 料盘 | 配合霍尔传感器触发脉冲 |

## 3.3 默认引脚分配

ESP32 默认引脚（全部可改，见第四节配置文件）：

| 引脚用途 | 默认 GPIO | 电气配置 | 说明 |
|---------|----------|---------|------|
| 收线盘电机 PWM | GPIO 4 | LEDC ch0 输出 | MOS 管驱动信号（单向调速） |
| 排线舵机 PWM | GPIO 5 | LEDC ch1 输出（14 位分辨率） | 舵机速度/方向控制 |
| Endstop 信号 | GPIO 14 | INPUT_PULLUP | 低电平触发 |
| 霍尔 A（从动轮） | GPIO 13 | INPUT_PULLUP | 中断，下降沿触发 |
| 霍尔 B（料盘） | GPIO 27 | INPUT_PULLUP | 中断，下降沿触发 |

> **避让引脚说明**：GPIO 0（Boot）、GPIO 1/3（TX0/RX0 串口）、GPIO 6-11（SPI Flash）不可用于本项目。GPIO 34-39 仅输入（无上拉）。

# 四、配置文件规范

## 4.1 设计原则

固件中存在**一个集中配置文件**（`include/config.h`），包含所有可调参数的默认值。APP 中也有对应的参数编辑面板，两者结构一致。

**参数生命周期**：

```
config.h 默认值  -->  首次启动写入 NVS  -->  运行时使用 NVS 值
                                          ^
                                          |
                              APP 下发覆盖 --> 写入 NVS
```

- **config.h**：编译时默认值，首次烧录或恢复出厂设置时使用
- **NVS**：运行时持久化存储，APP 修改的参数保存在此
- **APP 预设面板**：用户可创建多组预设方案，切换/编辑/删除，选中后下发至 ESP
- **恢复出厂设置**：APP 下发指令 -> ESP 清空 NVS -> 重新加载 config.h 默认值

# 五、固件开发要求

## 5.1 收线盘电机驱动（直流电机 + MOS 管，单向）

- PWM 无级调速，速度参数由 APP 实时下发（百分比 0-100%）
- 支持启动、停止、暂停
- 仅单方向旋转，不支持正反转
- 软启动：从 0 渐变到目标速度，时间可配（默认 1000ms）
- 速度限制：最低 20%、最高 100%（可配），防止堵转和过速

## 5.2 排线机构控制（连续旋转舵机 + 丝杆）

### 排线工作流程

1. **开机寻原点**：舵机慢速左行（SERVO_HOME_PULSE），直到 Endstop 触发 -> 位置归零
2. **定位到起始位置**：舵机右行到 TRAVERSE_LEFT_START（此位置可自定义，不一定等于 0）
3. **开始绕线**：收线盘启动旋转，排线舵机同步右行
4. **右端换向**：排线位置 >= TRAVERSE_RIGHT_END -> 舵机切换为左行
5. **左端换向**：排线位置 <= TRAVERSE_LEFT_START -> 舵机切换为右行，来回计数 +1
6. **周期性校准**：来回计数达到 CAL_INTERVAL_ROUNDS -> 舵机左行至 Endstop -> 位置归零 -> 回到起始位置 -> 重置计数 -> 继续
7. **循环**：重复步骤 4-6，直到任务完成

### 排线位置追踪

- 排线位置 = 相对于原点（Endstop）的 mm 距离
- 位置估算方式：运行时间 x 标定速度（SERVO_TRAVERSE_SPEED_LEFT/RIGHT）
- 位置估算存在开环漂移，通过周期性 Endstop 校准消除
- 校准后位置归零为绝对精确值，之后重新开始估算

### 位置换向逻辑

- **右端换向**：靠距离估算到达 TRAVERSE_RIGHT_END，切换舵机为左行
- **左端换向**：靠距离估算到达 TRAVERSE_LEFT_START，切换舵机为右行
- **周期性硬校准**：每 N 个来回强制回 Endstop 归零（不靠估算）
- 左/右位置、校准间隔均可在 APP 中自定义

### 寻原点行为

- 舵机以 SERVO_HOME_PULSE（慢速）左行
- Endstop 触发 -> 位置归零 -> 舵机停止
- 超过 HOMING_TIMEOUT 未触发 -> 报错（HOMING_FAILED）
- 寻原点期间收线盘电机不旋转

### 校准期间的行为

- 触发周期性校准时：**收线盘电机暂停**，排线舵机左行回 Endstop
- Endstop 触发后：位置归零，舵机右行回到 TRAVERSE_LEFT_START
- 到达起始位置后：收线盘电机恢复运行，继续绕线
- 校准过程中 APP 收到状态 = CALIBRATING

## 5.3 传感器逻辑

### 霍尔传感器 A（从动轮）

- 中断方式采集脉冲，下降沿触发，去抖动 5ms
- 从动轮每圈产生 2 个脉冲（可配）
- 出线长度 = (总脉冲 / 2) x (pi x 10.0)
- 用于实际出线长度计量 + 打滑检测对照

### 霍尔传感器 B（料盘）

- 中断方式采集脉冲，下降沿触发，去抖动 5ms
- 料盘每圈产生 4 个脉冲（可配）
- 料盘圈数 = 总脉冲 / 4
- 配合有效直径模型计算理论应收长度
- 用于打滑检测对照

### 有效直径动态计算模型

料盘绕线时线逐层叠加，有效直径随层数增长：

```
有效芯轴直径 = SPOOL_HAS_CARDBOARD ? 87.0 : 81.5  （mm，运行时选择）

每层圈数 = SPOOL_WIDTH / FILAMENT_DIAMETER
         = 68.0 / 1.75
         = 38.9 -> 38 圈/层

当前层数 = floor(累计料盘圈数 / 每层圈数)

当前有效直径 = 有效芯轴直径 + 2 x FILAMENT_DIAMETER x 当前层数

每绕一圈增量：理论应收长度 += pi x 当前有效直径
每进入新层：当前有效直径 += 2 x FILAMENT_DIAMETER
```

理论应收长度实时动态累加，随绕线层数自动修正。

### Endstop 限位

- 排线机构最左物理限位标记
- 低电平触发（INPUT_PULLUP），去抖动 20ms
- 开机寻原点 / 周期性校准时触发，排线位置归零
- 正常运行中不依赖 Endstop（靠距离估算换向），仅在周期性校准时使用

## 5.4 打滑检测（强制开发）

**检测原理**：料盘理论应收长度 vs 从动轮实测长度

```
偏差率 = |理论应收长度 - 实测出线长度| / 理论应收长度 x 100%
```

异常判定：

| 异常类型 | 判定条件 | 含义 |
|---------|---------|------|
| 打滑 SLIP | 偏差率 > SLIP_TOLERANCE（默认 10%） | 耗材在料盘上打滑 |
| 卡线 STALL | 料盘有脉冲但从动轮无脉冲，持续 > STALL_TIMEOUT（默认 3s） | 耗材卡住不动 |
| 断线 BREAK | 从动轮有脉冲但料盘无脉冲 | 耗材被拉出但料盘不转 |

**保护动作**：检测到异常 -> 立即停机 -> 上报错误码至 APP -> 等待 APP 确认后恢复

## 5.5 原点校准

| 触发时机 | 行为 |
|---------|------|
| 开机 | 自动寻原点，位置归零 |
| 运行中（周期性） | 每 N 个来回（默认 3），收线盘暂停，回 Endstop 校准 |
| 任务结束 | 排线回原点归位 |
| APP 手动触发 | 强制回原点（需在停止/暂停状态下） |

## 5.6 数据与预设存储

- 所有配置参数存储在 NVS（Non-Volatile Storage）
- 支持多组预设方案：每个方案包含完整的参数集（引脚 + 传感器 + 料盘 + 运动 + 舵机 + 电机 + 打滑参数）
- 预设操作：切换（加载到运行时）、保存（覆盖当前）、新增、删除
- 预设数量上限：10 组（可改）
- 实时上传数据：运行速度、料盘圈数、从动轮圈数、出线长度（实测 + 理论）、当前有效直径、排线位置、来回计数、距下次校准剩余来回数、设备状态、当前通信链路

## 5.7 双通信模式（BLE + WiFi）

### BLE 低功耗蓝牙

- 设备名固定：esp 绕线器
- 采用 Nordic UART Service（NUS）协议，兼容主流 BLE 库
- 用于近距离快速配网、快速控制
- 支持搜索、配对、自动重连
- 双向透传：APP 下发参数/指令，ESP 上传状态/数据
- 断线行为可配：CONTINUE（继续运行）/ STOP（停机保护）

### WiFi 局域网（APSTA 双模式）

- ESP32 使用 APSTA 模式：AP 热点 + STA 客户端同时在线
- AP 热点（ESP-Winder）做兜底配网入口，IP 固定 192.168.4.1
- STA 连接家庭路由器加入局域网，获取局域网 IP（如 192.168.1.x）
- TCP 服务端，监听 WIFI_TCP_PORT（默认 8080），AP 和 STA 接口均可访问
- APP 作为 TCP 客户端连接
- JSON 行协议（每条消息以换行符分隔）
- 适合大数据量、稳定传输

### 配网引导

- 手机连 ESP-Winder 热点，APP 通过 TCP（192.168.4.1:8080）发送 set_wifi 命令
- ESP32 在 APSTA 模式下连接家庭 WiFi（AP 热点不中断）
- ESP32 连上后立即通过 AP 的 TCP 连接回报局域网 IP（wifi_status 消息）
- APP 收到局域网 IP 后自动保存到本地（SharedPreferences）
- 手机切到家庭 WiFi，APP 用保存的 IP 一键快速连接

### 联网记忆

- ESP32 保存上次配网参数（NVS）
- 上电以 APSTA 模式启动：AP 热点立即可用 + 尝试 STA 重连上次局域网
- STA 重连超时 WIFI_CONNECT_TIMEOUT（默认 15s），超时后 AP 继续运行做兜底
- APP 保存配网 IP 到本地，下次直接一键连接

### 双链路特性

- 蓝牙、WiFi 可同时在线
- APP 可自由切换控制链路
- 指令、数据双向透传互通
- ESP 状态上报同时推送到两条链路（如均在线）

# 八、系统运行流程

1. 上电 -> APSTA 模式启动（AP 热点立即可用 + 尝试 STA 重连上次 WiFi）
2. 自动寻排线原点（舵机慢速左行至 Endstop，超时 30s 报错）
3. APP 连接设备（通过 AP 热点 TCP，或局域网 IP TCP）
4. APP 选择/编辑料盘预设参数，下发至固件
5. APP 调节运行速度，启动绕线任务
6. 排线定位到 TRAVERSE_LEFT_START -> 收线盘软启动旋转 -> 排线同步右行
7. ESP 同步采集双霍尔数据 -> 打滑检测 + 长度统计（含有效直径动态计算）
8. 排线右端估算换向、左端估算换向、每 N 个来回回 Endstop 硬校准
9. 异常自动停机上报 APP
10. 任务完成自动归位（排线回原点），APP 提示完成

# 九、实现细节规定

## 9.1 PWM 参数

| 设备 | 频率 | 分辨率 | 说明 |
|------|------|--------|------|
| 收线盘电机 | 1000 Hz | 10-bit（0-1023） | MOS 管 PWM 调速 |
| 排线舵机 | 50 Hz | 14-bit（us 映射） | 标准舵机，脉宽 1000-2000us。ESP32 LEDC 最大 14 位 |

> 舵机 PWM 值以微秒（us）表示，内部通过 LEDC 转换为占空比。

## 9.2 去抖动

- 霍尔传感器：软件去抖 5ms（中断内记录时间戳，5ms 内的重复触发忽略）
- Endstop：软件去抖 20ms

## 9.3 术语定义

| 术语 | 定义 |
|------|------|
| 趟（pass） | 排线从一端移动到另一端（左->右 或 右->左） |
| 来回（round trip） | 排线完成一个完整往复（左->右->左） |
| 校准间隔 | 每隔 N 个来回执行一次 Endstop 硬校准 |

## 9.4 设备状态机

```
IDLE -> HOMING -> IDLE
IDLE -> POSITIONING -> RUNNING
RUNNING -> PAUSED -> RUNNING (resume)
RUNNING -> PAUSED -> IDLE (stop)
RUNNING -> CALIBRATING -> RUNNING (校准完成恢复)
RUNNING -> ERROR (异常)
ERROR -> IDLE (APP 清除异常)
RUNNING -> COMPLETED -> IDLE (任务完成)
任意状态 -> HOMING (APP 手动触发，仅在 IDLE/PAUSED 允许)
```

## 9.5 单位规范

- 长度：mm（内部计算）/ m（状态上报）
- 时间：ms（短时）/ s（长时）
- 速度：%（电机）/ RPM（料盘转速）/ mm/s（排线线速度）
- 角度：度（不适用，连续旋转舵机无角度定位）
- 重量：不涉及（本机按长度计量，不按重量）

## 9.6 断线保护

- BLE 断开行为可配：CONTINUE（继续运行）/ STOP（停机保护，**默认**）
- WiFi 断开行为可配：CONTINUE（继续运行，**默认**）/ STOP（停机保护）
- BLE 和 WiFi 均断开时：按 BLE 断开行为处理（默认 STOP，停机保护）
- 断线后状态上报暂停，重连后恢复

## 9.7 任务完成判定

任务完成判定方式（APP 可选）：

- **手动停止**：APP 点击停止，任务结束
- **目标长度**：实测出线长度达到设定值时自动停止
- **目标圈数**：料盘圈数达到设定值时自动停止
- **料盘满载估算**：基于料盘外径和有效直径计算，当有效直径接近料盘外径时提示接近满载

## 9.8 出厂设置恢复

- APP 下发 factory_reset 命令
- ESP 清空 NVS 所有数据
- 重新加载 config.h 默认值
- 设备重启

## 9.9 固件 OTA（可选，后续扩展）

- 预留 WiFi OTA 升级接口
- 通过 APP 上传固件文件，ESP 接收并刷写
- 首期开发可不实现，预留架构空间

## 10.3 标定流程（组装后执行）

1. **舵机方向验证**：发送左行/右行 PWM，确认排线机构移动方向与预期一致，不一致则在 APP 中调换 LEFT/RIGHT 值
2. **舵机停止验证**：发送 1500us，确认排线机构完全停止。如微动则微调 STOP 值（1480-1520us 范围）
3. **排线线速度标定**：测量排线机构移动已知距离所需时间，计算出 mm/s，填入 SERVO_TRAVERSE_SPEED_LEFT/RIGHT
4. **电机最低转速**：从低 PWM 开始测试，找到电机不堵转的最低稳定速度，更新 MOTOR_MIN_SPEED
5. **霍尔传感器验证**：手动旋转从动轮/料盘，确认脉冲计数正确（每圈对应磁铁数）
6. **Endstop 验证**：手动触发 Endstop，确认信号正确读取
7. **打滑阈值微调**：实际绕线时观察偏差率，调整 SLIP_TOLERANCE 至合理值
